# Project Requirements

To run and develop the **OneChain Defense** dApp, you will need the following software and tools installed on your system.

## Software Prerequisites

### 1. Node.js & npm
- **Node.js**: Version 18.0.0 or higher is recommended.
- **npm**: Comes bundled with Node.js. Used for managing project dependencies.
- [Download Node.js](https://nodejs.org/)

### 2. Git
- Version control system to clone the repository.
- [Download Git](https://git-scm.com/)

## Browser Requirements

### 1. Modern Web Browser
- Google Chrome, Brave, Microsoft Edge, or Firefox.

### 2. Slash Wallet Extension
- You must have the **Slash Wallet** (or a compatible OneChain wallet) installed in your browser to interact with the blockchain features.
- Ensure it is configured for the **OneChain Testnet**.

## Project Dependencies
The project uses the following key libraries (installed via `npm install`):
- **React**: Frontend framework.
- **Vite**: Build tool and development server.
- **Kaboom.js**: Game library for the tower defense mechanics.
- **@onelabs/dapp-kit**: SDK for connecting to OneChain wallets.
- **@onelabs/sui**: Core Move/Sui blockchain interaction library.
- **ethers**: (Legacy/Utility) For general Web3 helpers if needed.
